Introduction

CasBadge is a badge maker for Moodle, part of the CCTK (Caspar's Cool Tool Kit). There are two versions: CasBadge (the standard badge maker covered by this guide) and CasBadge3D, a beta that adds STL file generation for 3D printing.

Reach it via the CCTK at caswynne.github.io/psychactivities2, or directly at the badge maker page.

The interface

  • App name / version — shows the current app name and version.
  • Position grid toggle — turns on a grid overlay to help you position icons and text.
  • Moodle preview window — a live preview; a guide only, as device settings may change how the badge displays.
  • Undo — removes your last action.
  • Auto-fit — ensures all elements sit safely within the badge boundaries.
  • Import badge — imports SVG files exported from CasBadge only; SVGs from other sources will not load.
  • Export badge — exports as PNG, JPG or SVG.
  • Settings panel — where you build and fine-tune your badge.

Exporting

  • PNG / JPG — image formats. These cannot be re-imported into CasBadge.
  • SVG — a vector file, and the only format CasBadge can re-import for further editing.

Export as SVG if you want to keep editing later.

Badge shape

Four shapes, each intended for a badge level: Square (Level 4), Pentagon (Level 5), Hexagon (Level 6) and Circle (all others). Advanced settings add a scalloped (rosette) edge, scallop count and depth, and border width (larger = less white space in the centre).

Colour style

11 preset colours, each with a metallic gradient. The colour affects both the border and the decorations. Advanced settings let you change individual gradient colours and add or remove colours (minimum of 2).

Badge text

Text is a required Title (max 16 characters, also used as the export file name) and an optional Subtitle (max 40 characters). Text resizes automatically as you type — keep it short for best visibility. Advanced settings adjust size, colour, X/Y position, curve, curve radius and alignment (L/C/R and T/M/B).

Icons

Icons are SVG images that scale without losing detail. Add them three ways: pick a pre-set example (or search the Iconify database of 300,000+ icons), import a Tabler icon via its SVG link, or upload your own image (PNG/JPG — note scaling affects clarity). Each icon gets its own settings box for X, Y, scale, colour and alignment.

Decorations

Small, non-topic details for extra flair. Every badge starts with two laurels and a central sparkle. Other options include a left/right laurel, sparkle, divider, ribbon, crown, dot divider and starburst. They edit the same way as icons.

Level marker

Add a level pill: No marker, Level 4, Level 5 or Level 6.

Known bugs

  • Curved text X and Y adjustments not working (title and subtitle).
  • Curve radius repositions text vertically instead of only changing curvature.
  • ↺ Style (reset-to-default) not working; may be removed.
  • Right laurel renders incorrectly in the decorations grid.

Found a bug that isn't listed? Email c.wynne@leedstrinity.ac.uk.

Export your badge

Moodle's badge system accepts PNG and JPG. Maximum file size: 256 KB.

PNG —

  • Works in Moodle's badge system
  • Keeps transparency — clean shape edges
  • Crisp, lossless at its export size
  • Fixed resolution — blurry if enlarged

JPG —

  • Works in Moodle's badge system
  • Smallest file for photo-style badges
  • Fixed resolution — blurry if enlarged
  • No transparency (white background)

SVG —

  • Crisp at any size — never pixelated
  • Very small file; easy to edit later
  • Re-openable here for further editing
  • Not accepted by Moodle's badge system — use PNG or JPG for the badge itself

STL —

  • A real, printable 3D relief medallion
  • Text & icons raised on a base plate; hanging loop for a ribbon
  • Zip also holds the editable SVG — re-import to edit later
  • Colours & gradients are lost (shape only)
  • Very small text may be too fine to print — size up if warned
  • Not for Moodle — this is for a 3D printer

3D-print settings (STL)

Larger medallions print small text and fine detail more reliably. All measurements are in millimetres.

Raise height can be negative to engrave the text/icons into the plate instead of raising them. Bevel, inner frame, and per-text bevel toggles live in Badge shape and Badge text advanced settings. Features thinner than the printer's nozzle (about 0.4 mm) are left off the model and you'll be told — making the medallion bigger is the simplest fix.
